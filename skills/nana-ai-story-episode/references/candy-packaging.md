# 糖果贴纸包装（Remotion）

组件代码在 `../templates/candy-kit.tsx`，渲染脚本 `../scripts/render.mjs`。

## 品牌规范（娜乌斯嘉）

| 用途 | 色值 |
|---|---|
| 底色 | 奶油 `#FFF4EA` + 浅点阵 |
| 描边、投影、正文字 | 深莓墨 `#3B2340`（不用纯黑） |
| 主强调（每张卡只用一处） | 糖果粉 `#FF6FA8` |
| 辅助（角色/信息分色） | 奶黄 `#FFD84D`、薄荷 `#5FD3B3`、浅紫 `#B9A7FF`、蜜桃 `#FFB38A` |

- **贴纸**：5–7px 深莓墨描边 + 右下实色投影（不模糊）+ 大圆角或胶囊 + 歪 1–8°。
- **字**：思源黑体 Heavy，深莓墨。不要白字黑边、不要黄红大字。
- **动**：`popIn` 冲到 1.12 回落、摇两下；`sinkOut` 0.25 秒缩小下沉。禁止淡入淡出和匀速滑入。
- **声**：贴纸进场 pop、打勾叮、印章啪、转场嗖；BGM 很轻（约 0.07 音量），原片原声段落 BGM 让位静音。

角色分色例：克肆薄荷、洄光浅紫、娜娜蜜桃。名牌、字幕说话人、便签都用同一个颜色，观众看颜色就知道是谁。

## 画面组织

- **所有视频都装进贴纸窗 `Win`**，左上角带标签（“Claude 做的”“GPT 第一版”“克肆 · AI助理”）。观众一眼知道这是谁做的、谁在说。
- **大窗** 1456×819 居中；**对比**用左右两个窗，各自歪一点；**讲解**时角色窗放右边大一些，左边小窗插入他正在讲的作品。
- **停帧圈注**：原片在问题帧冻结（`freezeAt`），手绘圈 `Scribble` 圈出穿模，再盖一个印章（例：“技术检查：通过”然后被划掉）。
- **章节卡/规则卡/总结卡**：一张大贴纸，标题小胶囊 + 1–2 行大字，打勾逐条亮。
- **片尾关注卡**：头像（博主真人片段）+ 账号名 + “关注”按钮被按下变成“已关注 ✓”。

## 字幕

- 一句一条：左边说话人名牌（彩色小胶囊），右边奶油胶囊句子，屏幕底部居中。
- 重点词用 `{}` 包住，渲染时变糖果粉并放大 1.12 倍。
- 时间来自口播识别：`at(T, c0, a, b)` 把录音里的 a–b 秒换算到时间线（T 是这句在时间线上的起点，c0 是这句在录音里的起点）。
- 字幕写她实际说的话。口播里的模糊指代（“他”），字幕里可以写明（“GPT”），并在画面上加名牌。

## 版面避让

- 右侧 1/6 留给平台按钮；博主小头像放左下；字幕底部居中；角标放右下最边上、比字幕更低。
- 每次改动后渲几张关键秒的静帧看：角标、标签、头像有没有压到画面或彼此重叠。
- 片尾一行小字说明真实来源。

## 时间线写法

- 每个段落用 `<Seg a={开始秒} b={结束秒}>` 包起来，段内元素的 `dur` 等于段长，出场动画才对得上。
- 口播用 `VO` 表（id、时间线起点、录音起点、时长）统一驱动：声音、字幕、小头像都读这一张表，改一处全片跟着动。
- 音效用一个列表 `sfx(秒, 文件, 音量)`，跟贴纸进场时刻写在一起。
- React 规则：hooks（`useSec()`）要在组件最前面调用，不能放在提前 `return null` 之后。
