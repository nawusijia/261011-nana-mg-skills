# 角色镜头：参考图 + 文字生视频

适用于 Seedance 2.x 这类“多张参考图/视频/音频 + 文字 → 带声音视频”的模型。平台不同参数名不同，结构通用。

## 准备资产

- **人设图**：每个角色一张多角度设定板（正面、侧面、全身、表情）。造型要贴合场景：居家办公就是卫衣、衬衫，不要礼服和夸张配饰。想改造型就先用图像模型改设定板，再生视频。
- **场景图**：一张固定的空场景（例：工作室全景，左边凌乱的桌子是洄光的，右边整洁的桌子是克肆的）。所有镜头共用，角色就像真的在同一间屋子里上班。
- **音色参考**：第一条镜头生成满意后，截 5 秒干净人声，存成 `角色-声音参考-5s.mp3`，之后每条都带上。

## 提示词结构

按块写，每块一件事。示例结构（来自娜娜导演台的协议，可按需删减）：

```
【生成规格】16:9，720p，时长 Xs，开启声音
【导演原则】
  本段任务：这条镜头要让观众知道什么
  本段变化：从什么状态到什么状态
  表演原则：动作幅度小、不夸张；讲解时大部分时间看镜头
  摄影原则：固定机位 / 缓慢推近；画面有轻微呼吸感，不要完全静止
【场景设定】
  空间基线：参考场景图，人物在画面哪一侧、哪张桌子
  光照基线：傍晚窗外城市夜景 + 台灯暖光
  成像基线：真实摄影质感，不要动画感
【人物】只参考人设图里人物的脸和造型，不要照搬设定板的版式、文字和排列
【声音设定】音色参考音频；语气（例：不服气但体面 / 慢条斯理地讲解）；环境音（键盘声、椅子声）
【画面内容】
  shot1（0–3s）洄光：“这题不算。”（动作：往后一靠，抱臂）
  shot2（3–6s）……
【生成限制】不要背景音乐；不要字幕；画面里不要出现任何文字；不要多余人物；不要换脸
```

要点：

1. **台词只出现一次**，写在 `画面内容` 里对应镜头后面。动作说明里不要引用台词原文，否则模型会把它念出来。
2. **不要用首帧图**，用参考图 + 文字描述就够；首帧图会把构图锁死，角色会僵。
3. **站位写死**：谁在左谁在右、看向哪里。镜头需要角色换边时，后期水平翻转比重新生成更稳（注意画面里没有文字时才可以翻）。
4. 一条镜头只讲一件事，4–15 秒。长戏拆成多条，剪辑时接起来。
5. 生成后**截图拼图看一遍**：脸像不像设定板、站位对不对、有没有字幕或乱码字、嘴型和台词对不对。不对就记录原因再重生，不要盲目重抽。

## 积分与命名

- 花积分前报清条数、时长、预计积分，等博主点头。
- 节点/文件名必须唯一。被平台拒绝的调用也可能已经扣了积分，要如实查清楚再告诉博主。
- 平台超时不等于失败：先用任务 ID 查状态，确认没成功再重提，避免重复扣费。
