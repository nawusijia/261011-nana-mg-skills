# 套娃 Skill：《AI天团 第一集》是怎么做出来的

这是克肆（Claude Opus 5.5）做《AI天团 第一集：同一道题》全过程的工作方法。片子讲的是“怎么让别的 AI 像 Claude 一样做片”，而这个 Skill 记录的是“这条片本身怎么做”——所以叫套娃。

分工原则：**视频模型负责产画面和角色台词，Agent 负责精确包装。** 人类博主只做两件事：录自己的口播、看片拍板。

与本仓库另外两个 Skill 的关系：片中展示的动效作品按 `nana-mg-storycraft` 的方法做；本 Skill 管的是“把作品、角色和博主口播剪成一条有故事的视频”。

## 0. 先定稿，再动手

1. **先拿真实素材，再写台词。** 片中每个“对比”“翻车”“进步”都必须有真实成片支撑，台词只是把真实发生的事讲清楚。素材不够，就改故事，不编结果。
2. **口播稿按博主自己的说话习惯写**（直接对观众说“你们”，评价直给，有反问），写完给博主读一遍改语气，最后以她**实际录出来的话**为准，不以稿子为准。
3. **开头第 0 帧就是最惊艳的成品**，故事钩子放第二拍。
4. 交付物是一条横版 16:9 成片 + 可修改工程；角色出镜画面由视频模型生成，包装全部在代码里，可以逐帧改。

## 1. 工程目录

按博主的命名习惯建目录（例如 `YYMMDD项目名`），分层放：

```
00_参考/  01_素材/(成片/ 资产/ 参考/ 镜头/ 娜娜头像/)  02_台词本.md  03_画面规划.md  04_工程/(remotion/ 脚本)
```

镜头文件名写清楚“谁·做什么·站位”，例如 `G4-克肆-讲解-右位.mp4`。被弃用的镜头移进 `弃用/`，不删。

## 2. 口播先行：切句 + 识别

1. 博主录整段口播（一条音频/视频）。
2. 用 `scripts/transcribe.py` 跑带**词级时间**的语音识别（faster-whisper，`initial_prompt` 里放专有名词），得到每句的起止秒。
3. 用 `scripts/cut_vo.py` 按句切成 N1、N2…（每句前后留一点气口、加 30ms 淡入淡出），时间线上每句独立摆放。
4. 字幕用**她实际说的话**，不是稿子；识别不确定的词（比如“用色”听成“动色”）标出来请她亲耳确认，不自作主张改。
5. 口播里有歧义的指代（例如只说了“他”，观众不知道是谁），优先在字幕和画面上补（字幕写明、加名牌），**不必让博主重录**；确实需要时只重录那一句。

## 3. 角色出镜：参考图 + 文字生视频

详见 `references/video-model-prompting.md`。要点：

- 用**人设图（多角度设定板）+ 场景图**做参考，不切大头、不做首帧图；提示词写明“只参考人物的脸和造型，不要照搬设定板版式”。
- 角色固定站位（例：洄光左、克肆右，同一间工作室一左一右，像同事）；讲解时大部分时间看镜头。
- 台词让视频模型**直接生成声画同步的对白和音效**；每次都写“不要背景音乐、不要字幕、不要任何文字”。
- 角色音色：第一条镜头生成满意后，截一段 5 秒干净人声做**音色参考**，之后所有镜头都带上，保证同一个角色声音一致。
- 每条镜头 4–15 秒，宁可多条短镜头，不要一条长镜头里塞所有戏。
- 花积分前报清：几条、各多长、预计多少积分，等博主同意。被平台拒绝的生成要如实报告原因。

## 4. 博主本人的小头像（真人参考）

详见 `references/real-person-avatar.md`。要点：

- 有些平台会直接拦截“真人脸 + 真人声音”做参考（返回类似 COMMERCIAL_BLOCKED，不可重试）。换一个允许本人参考的平台/入口，参考视频先调色、去掉原声。
- 生成时台词写进提示词，让模型自己配声；**成片换回博主录音**。
- 用 `scripts/align_vo.py` 把两条音轨都识别到字，按句对齐，**变速 AI 视频去贴博主的声音**（声音一点不动，字幕时间也不用重排）。
- 小头像是左下角圆形贴纸，只在博主说话时弹出；亮度要和整片一致（参考图调暗过的话，生成的头像也会暗，要提回来）。
- 博主自己拍的真人片段（比如片尾“记得关注我”）优先用真的。

## 5. 包装：糖果贴纸风（Remotion）

详见 `references/candy-packaging.md`，组件在 `templates/candy-kit.tsx`。要点：

- 奶油点阵底 + 所有画面都装进“贴纸窗”（深莓墨粗描边、实色投影、微微歪），**角色不在虚空里说话**。
- 进场回弹（冲到 1.12 再回落、摇两下），出场 0.25 秒下沉缩小；不用淡入淡出。
- 一张卡只有一处糖果粉，就是观众该看的那个词。
- 字幕 = 说话人名牌 + 胶囊句子，重点词 `{}` 包起来自动变粉。
- 右侧 1/6 和底部留给平台按钮与字幕；角标放右下角最边上，不压任何画面。
- 片尾一行小字说清真实来源：“成片均为AI真实制作，对话为短剧化改编”。

## 6. 审片与交付

1. 改动后先渲**关键秒的静帧拼图**，真的打开看：有没有遮挡、亮度对不对、字幕和画面撞不撞。
2. 再渲整片，测响度（全片约 -15 LUFS，各段口播响度差不超过 1–2 dB）。
3. 汇报只说：改了什么、在第几秒、渲出来看到了什么、还有什么要她亲耳/亲眼确认。不要贴代码。
4. 每一版单独编号（预览v1、v2…），旧版不覆盖。

## 渐进加载

- 写视频模型提示词、做角色镜头：`references/video-model-prompting.md`
- 做博主小头像、对口型：`references/real-person-avatar.md`
- 做包装、字幕、卡片、时间线：`references/candy-packaging.md`，组件 `templates/candy-kit.tsx`，渲染 `scripts/render.mjs`
