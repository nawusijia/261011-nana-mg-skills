# 几何身份与运动导演指南

## 1. 同一对象跨状态

常见失败结构：

- 第一个场景里文字淡出；
- 第二场景独立生成一批随机节点；
- 第三场景独立出现透视盒子；
- 依靠满屏颜色冲刷遮住断层。

这只是转场，不是变形。除非刻意做拼贴蒙太奇，主题 MG 要优先让观众**看见同一东西变化**。实现上可用一个持久对象数组和有限状态逻辑：起始位置、目标位置、身份 ID、纹理、形态、触发时间；每帧读取全局进度计算。不意味着 React 必须单一组件：组件可拆，但共享同一事实源。

## 2. 粒子→文字或 Logo 的同源轮廓

1. 确定落点字体/字重/轮廓与最终画面坐标；把轮廓 rasterize 到 RGBA 资源或提 SVG path。
2. 按像素 alpha 阈值、路径等弧长或 Poisson disk 采样落点。
3. 根据颗粒大小和面积分配数量，避免字的细笔画消失。
4. 将源位置与落点按极角、距离或最小搬运距离配对；确保视觉上是「收」而非「炸」。
5. 同一字体轮廓渲染实体最终状态；过渡末尾用相同坐标和形状淡合，不能另用浏览器字体排一遍碰运气。
6. 固定随机种子。所有动画位置只依赖 frame/event constants，做到逐帧可复现。

注：克肆实例使用 PIL 的字形 PNG + glyphs.json 目标点，实体态也是同一张 PNG。可参考这个做法，但应为当前创意重新选图形。

## 3. 运动定向：不是万物缓入缓出

定义动作个性（例，不是硬规则）：

- 认识：细微变化、微停，建立观众知觉；
- 触发：短促、明确、主物体首先响应；
- 传播：距离驱动延迟、波前、从主要区域向外；
- 汇聚：远点先启动，曲线路径，最后同时抵达；
- 成形：减速、稳定、形态完成；音符有归宿；
- 收束：摄像机保持阅读空间，静态就是设计。

每个曲线应能解释一句「为什么此时快/慢」，不只是使用 spring/sin/ease。

## 4. 运动审查方法

- 每 0.5 秒抽一帧：连续三格变化很小，可以是**有意悬停**，但不能默认为好。
- 对事件前后额外抓精确帧：例如触发前 1 帧、触发当帧、后 3/9/18 帧；检查元素瞬移、脱落、叠字。
- 在 25%、50%、100% 分辨率检查文字和粒子密度。
- 审剪辑感：有没有视觉焦点交接？从上一动作到下一动作，观众是否知道该看哪里？
- 不迷信无剪辑、一镜到底、少彩色；都要从题目、用户风格和剪辑叙事推导。
