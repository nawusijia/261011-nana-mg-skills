# 动效质感、S曲线揭示与排版

## 可见的细节运动

先找静帧里最像贴纸的细部，再让它与空间、事件关联。完整对称圆环的自转不改变轮廓，观众看不到：可以使用亮弧段、少数轨道点、倾斜进动和前后深度。检查0/0.5/1/1.5秒连续帧，轨道点应沿同一环运动，不能绕主体随意漂移。装饰强度不能盖过主角或把冷静等待做成杂乱循环。

## 加速、弹性与到达时点

连续光路共用一个全程进度，不对每段分别ease导致中继处反复停顿。先按弧长分配每个节点的归一化路径位置f，再由速度曲线的逆函数得到真实到达时间；画面与音效共用导出的事件数据。

例：easeInOutQuint，适合此次快速揭示，其他项目可选择更柔和的Bezier或smoothstep：

```js
function ease(u) {
  u = Math.max(0, Math.min(1, u));
  return u < .5 ? 16 * u ** 5 : 1 - (-2 * u + 2) ** 5 / 2;
}
function inverseEase(f) {
  return f < .5 ? (f / 16) ** .2 : 1 - ((1 - f) / 16) ** .2;
}
// 真正的到达时刻，不是线性分配的时间。
const arrival = start + duration * inverseEase(pathFraction);
```

收到信号/接触/激活后可用阻尼回弹，如 `1 + A*exp(-d*t)*sin(w*t)`；A控制幅度，d控制落稳，w控制频率。按对象重量与剧情决定参数，普通星点不需要夸张跳跃。保证触发前后尺寸连续，并检查逐帧采样；公式不是视觉通过证据。

## 从局部到庞大整体

AE式速度图中，位置S曲线对应中段高、两端低的速度；不是把速度本身简单设成S形。设计顺序：

1. 原始主体、连接和远景节点放在同一个世界坐标里；初始大部分世界在画外。
2. 定义镜头启动、峰值、落稳与音乐落点。结尾字幕在落稳后给独立阅读时间。
3. 用 `camera = start + (end-start)*ease(u)` 驱动位置/深度，透视投影产生视差。尺度、节点密度、前后景和屏幕占比共同决定冲击力，增加数量不是唯一解。
4. 避免相机拉远的同时让新图凭空出现。若节点要沿波前点亮，检查传播结束与全景揭示的关系；允许余波，但说明导演意图。
5. 每2–3帧抽取揭示段，核对加速、最大位移、减速、遮挡、跳变和最终构图；同时检查位置差分的速度。数学首尾速度归零不保证屏幕空间的观感舒服。

《回响》V3示例：9.55–11.20秒，深度1150→4350，760节点四旋臂。只是该片试验参数，不是以后所有动画的默认预设。

## 排版跟随镜头

用实际字体和目标分辨率量字形（Canvas measureText的actualBoundingBoxAscent/Descent或DOM矩形）。baseline不是上边界；“呼叫”下面的条与状态字曾因此重叠。

为标签、指示器、状态字定义各自的屏幕矩形和留白；需要时检查交叠。主要检查事件前后、主体缩放最大时、拉远途中与最后一帧。近景标注随镜头拉远可淡出，最终主题在固定安全区域排版。字号、行距和位置依当前画幅确定，勿把16:9像素值机械复制给竖版。
