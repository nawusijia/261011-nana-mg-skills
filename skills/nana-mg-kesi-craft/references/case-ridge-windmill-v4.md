# 案例｜折纸山脊“狗牙”与风车闪烁：V3→V4真实返工

> 来源：洄光（GPT）制作的《把风装进纸里》（paper-wind-world），源工程在作者本地，未随仓库公开。
> **本文件是实跑后的技术复盘，不是声称所有 CG 穿模均可自动检测。** 可给其他 Agent 逐步读取并复用工艺方法。不要直接复制作品剧情和设计。

## 真实用户反馈
1. 山尖有密集“锯齿、狗牙”，之前增加少量网格和关闭重复模型仍未解决。
2. 风车旋转时不同颜色面片抢闪；用户怀疑两个不同颜色的面叠在一起。
3. 用户指出，机械验收报告无权代替高清画面观察。之前 V1～V3 反复犯下“代码看着没错，最终截图错误还在”的失职。

## 查到的两类不同根因

**地形不是一个低级的“调抗锯齿”问题。**
V3 `PlaneGeometry(12.72,10.72,144,124)` 的高度由尖锐纸折高度函数驱动，同时 `paper.flatShading=true` 使每个三角面拥有截然不同的法线。山脊高度变化跨越相邻网格位置后，尖脊边缘的**投影轮廓和明暗边界同时出现细小阶梯**。把网格单纯提高到280×242、关闭flat shading后，高清图上仍能看到一排细牙，必须看图再修。

**风车不是笼统的“动画缓动不好”。**
旧风车用5片 `BoxGeometry(.18,1.04,.027)`，每片几何中心共用相同局部轴心，半径起点落在转轴中央且z坐标同层；旋转时多个扇叶根部同时占有空间，深度与阴影竞争。轴心还有额外球体，与主轴盖视觉重叠。这个具体例子的修复不应只是全局`polygonOffset`或关闭depthTest，那样会隐藏错误，而不消除重合面。

## 实际修法

### 山脊
- 将细分网格扩大为 `PlaneGeometry(12.72,10.72,280,242)`。保持同一张纸拥有地形，不允许重叠生成第二个mountain mesh。
- `paper.flatShading=false`；逐帧根据新的几何重新计算顶点法线，保留高度场本身形成的折线而非粗暴地涂平模型。
- 地形顶点先统一读取`paperHeight(x,z,t)`；随后进行**半径仅1个网格单元的两步tent smoothing**：
  - x方向 `[0.25,0.5,0.25]`；
  - z方向 `[0.25,0.5,0.25]`；
  - 再`position.setY`、`computeVertexNormals`。
  这是只针对采样误差的小尺度修复；不要给整个山坡粗暴做10px模糊或扔掉折纸感。
- 旧版`PCFSoftShadowMap`在当前Three.js被废弃并自动回退，改成正式支持的 `PCFShadowMap`，配合`normalBias=.017`减轻阴影自遮挡，而不是只改shadow质量。
- 一定对比相同帧、相同相机、相同局部区域的**高清近景**，不要用20张很小的时间拼图来宣称解决了山脊细牙。

### 风车
- 5片薄平面改为5片有真实厚度（`ExtrudeGeometry`深度0.045）的**独立梯形纸叶片**，单片从半径0.225开始，外伸至1.22，左右有斜边。内侧先留空，让每片之间不共面、不占据同一轴点。
- 叶片只允许绕各自的正确转轴旋转；5片叶片间隔72°，根部半角`atan2(.062,.225)`约15.4°，小于36°的半扇区角；因此根部有明确空隙。
- 给中心安装一个前置独立金色轴盖`rotorCap.position.z=.076`遮住空隙；删掉额外`shaft`球体，否则近景会看到两颗不合理金色球。
- 对极薄的扇叶禁用阴影投射与接收，明确自身前后层次；*不能*简单把五片互穿叶片全部`depthTest=false`。
- 用镜头专用`?qa=windmill`特写测试，抽取6.00/6.03/6.07/6.10、7.00/7.03/7.07、8.00/8.03/8.07秒，逐帧检查不同颜色有没有忽然争抢前后关系。

## 实际验证证据（原工程内的文件，供照着做）

- 保留了 V3 原工程和视频快照（`versions/v3-before-v4/`）。
- V4最初加密网格仍有锯齿的高清近景（`ridge-zoom`）与微幅顶点平滑后的同机位高清近景（`ridge-smooth`），3.80 / 6.50 / 8.50 秒各一组。
- 风车专项近景10帧拼图；该图产生于去除多余轴心球**之前**，所以其中出现的多余金色球体也成为真实返工依据，后来源码已经去掉。
- `film/geometry-audit.mjs`：防旧几何回归的**静态+几何数值门禁**；检查细分数、flat shading、softenTerrain、厚度扇叶、中心盖、危险旧几何消失，此外保留房屋/树木/鸟的地形采样。
- 技术报告：300帧、10秒、30fps、540p带音轨，帧差最大的时段集中在6.3～6.9s主动镜头拉远的连续阶段；不是所有小物件闪烁的最终证明。
- 最终高清 1920x1080 成片，配半秒时间拼图与技术数据。

## 必须强制的QA门禁

1. CG类项目**至少一个微距局部审片**，重点看山脊、动态薄片、同色异色共面材质；光看720p或全片0.5秒拼图不算过。
2. 大于或等于3帧的**同机位连续截图**，检查风车转动中的颜色、面片遮挡和阴影；红黄蓝等交错扇叶尤其容易暴露z-fighting。
3. 同一相机同一时间**返工前后并排对比**，防止“修模型→只是换了一个观感问题”。所有源文件/时点保持可追溯。
4. 检查**网格高度函数的连续性、法线策略、投影锯齿、影子bias**，必要时三者一起修，但只使用足够的小范围顶点滤波。
5. `ffprobe`、音量、黑帧通过只代表*文件规格合格*；视觉是否高级、是否真的无闪烁穿模，必须结合大图、运动和用户的最终观看反馈。没有用户确认不要给出“100%彻底修复”的断言。
